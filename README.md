Your private thoughts belong to you. Refloow Note Studio delivers absolute privacy for your digital notes, combining powerful encryption with a completely offline, login-free experience.

You deserve a secure place to store your most important ideas, passwords, and personal reflections. Trusting external servers with this sensitive data often requires giving up control. Refloow Note Studio was built to give that control back to you. It provides a safe, organized space to manage your life without anyone looking over your shoulder. Every word you type stays exclusively on your own device, protected by robust local security measures.

## Features

- Minimal dependencies
   - there is just electron and thats it.

- Encryption:
   - App wide encryption
   - Folder Specific Encryption
   - Adding and enabling encryption is seemingless
- Settings:
   - App theme settings (dark & light)
   - Note font settings
   - ui scale settings
- App management:
   - Creating notes
   - Creating folders
   - Creating trackers
- Smart Saving:
    - Every change auto saves (no progress loss)
    - User preferences auto save (position of panels, shown or hidden)
- Drag & drop .txt files from desktop to auto import and convert into notes in the app (works for multiple at the same time too)
- Management:
    - reordering of folders
    - reordering of notes in folders
    - note selection for bulk operations
    - Delete all selected folders
    - move all selected folders
    - delete all selected notes
    - move all selected folders
    - moving notes from folders
    - renaming folders
- Trackers panel (can be hidden or shown)
- All created notes unless a folder is selected are default made in unsorted
- search bar that works cross app, displaying all results, notes, folders, trackers and such.
